## Changes fixed before execution

- Model selects a data-edge ID and beta group once per child; each choice is a
  schema enum bound to that child's valid predecessor edges. The compiler derives
  parents and traceable evidence from that single selection. No duplicated citation
  list or unsupported uniqueItems constraint in the decoder schema.
- Plain-text connection/sharing/falsifier explanations remain unproven. Correct
  edge-to-feature mapping is enforced by construction, not credited as model reasoning.
- Compiler owns greedy disjoint-round scheduling, counter preparation and COST.
  LLM owns asset-exchange graph and beta sharing. This is a new lowering contract;
  scheduling is not claimed to preserve the unitary of a previously ordered program.
- Same financial universe, coefficients, frozen numerical transport and one layer.
  Caps use the previously saved **unscheduled fixed one-layer baseline** in
  improvement_v1, rather than the tight scheduled-path cap that excluded all rules/
  random v1 controls. No unbounded depth allowance. All methods receive the same caps
  and compiler scheduling. This changes more than interface format, so v1-v2 gains
  cannot be causally attributed solely to syntax or model improvements.
