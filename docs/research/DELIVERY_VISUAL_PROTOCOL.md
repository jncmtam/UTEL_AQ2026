# English documentation and visual evidence delivery

Date: 2026-11-04, Asia/Ho_Chi_Minh. Written before generating this visual bundle.

This continuation packages existing measurements; it does not select a model,
optimize a circuit, reopen held-out strategy outcomes or launch inference.
The qualification protocol remains the authority for future experiments.

## Scope and rationale

Make the maintained US workflow, entry-point documentation and decision interfaces
readable in English. Preserve original historical protocols, raw responses, source
snapshots and results. Archive superseded Vietnamese entry-point documents with
their original bytes and replace their root entry points with English guides.
Legacy accepted Vietnamese mandate syntax remains a compatibility input format.

Generate figures with Matplotlib from recorded JSON/JSONL evidence. Show data
coverage, unresolved corporate-action labels, model readiness, the confirmation
threshold, objective distortion, preparation resources and measured allocated
quality. Explain ownership and dependency order using Mermaid diagrams. A static
HTML gallery provides an offline browsing alternative to GitHub rendering.

## Presentation rules

- Counts of clean price rows are numerical hygiene, never verified security identity.
- A tokenizer pass is not a generation pass; missing experiments are labeled unrun.
- The 72/72 reliability curve is a protocol illustration, never observed model data.
- Training objectives use their actual units. Seed ranges are descriptive, not
  confidence intervals over markets. Report the stronger classical control.
- Preparation resources include workspace and compiled cost. They are logical
  all-to-all counts, not routed hardware costs. Every quantum run shown is simulated.
- Development-only return diagnostics remain development-only. No new returns or
  financial effects are computed from the proposed final test.
- Record input hashes, generator source and presentation assumptions beside figures.

## Acceptance and stop rule

Run the full software suite, targeted static checks, link checks and language scan
over the maintained surface. Inspect every new figure and the gallery for readable
labels, units and limitations. Use a new results directory rather than overwriting
completed evidence. No GPU allocation is needed for this delivery. Financial value,
model qualification and scaling remain blocked until their substantive gates pass.
