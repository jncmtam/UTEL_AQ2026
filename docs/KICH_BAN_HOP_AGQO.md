# Demonstration discussion guide

1. State the account's existing holdings and new mandate.
2. Show whether the requirements can be met and explain conflicts.
3. Compare holding, a strong classical reference and quantum proposals using the
   same financial objective and allocator.
4. Show trades, costs, tracking, circuit resources and verification evidence.
5. Identify which gates belong to the LLM and which belong to the compiler.
6. Report measured improvements and negative results, with the dataset and
   simulator limits. Do not claim market value before the data audit passes.

The original Vietnamese discussion notes are preserved under `docs/legacy/`.
