# Specialist interface probe

This is a three-request interface diagnostic. Native code and GateIR transfer are different tasks. No production model is qualified.

| Task | Valid | Error |
|---|---|---|
| native_bell | False | Unsupported native program construct or size. |
| native_cost | False | Unsupported native program construct or size. |
| gate_ir_transfer_n6 | True |  |
