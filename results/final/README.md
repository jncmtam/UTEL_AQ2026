# Bằng chứng thực nghiệm V3

Thư mục này lưu các bảng kết quả, cấu hình, lịch mạch đã huấn luyện, mạch OpenQASM và nhật ký LLM của lần chạy V3. `run_manifest.json` ghi mốc huấn luyện, mốc kiểm định và mã băm của dữ liệu giá. Đọc [báo cáo kết quả](../../docs/RESULTS.md) để xem các bảng theo thứ tự thí nghiệm.

Ghi kết quả chạy mới ra thư mục riêng. Dùng bản sao của thư mục này nếu muốn phát lại nhật ký mà vẫn giữ bằng chứng gốc. [Hướng dẫn tái lập](../../CHAY_THU.md#đối-chiếu-bằng-chứng-đã-lưu)
